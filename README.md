# AlphabetAndThings

一款面向三岁儿童的中英双语字母、数字与常见事物认知小游戏。

- 仓库：https://github.com/KiwiFundHongning/AlphabetAndThings
- GitHub Pages（合并后启用）：https://kiwifundhongning.github.io/AlphabetAndThings/
- 第一阶段字母：A–P、R–U、W、Z（暂不包含 Q、V、X、Y）

## 最简单的游戏入口

在项目最外层双击 **`打开游戏.html`** 即可开始，不需要安装、登录或联网。

要分享给朋友时，只需压缩整个 **`AlphabetAndThings-分享版`** 文件夹。朋友解压后双击其中的 **`打开游戏.html`**，Windows 和 Mac 都会使用默认浏览器运行。请不要只发送单独的 HTML 文件，因为旁边的 `audio` 和 `things` 文件夹包含本地声音和图片。

## 当前体验

- 每轮随机练习 5 题：3 个字母物品题和 2 个数字题；物品会在同一首字母的多个选项之间轮换。
- 内置 82 个常见物品，包含动物、工程车辆、其他交通工具、水果、蔬菜、自然事物、食品和日用品。
- 默认数字范围为 0–20。新手和简单难度在中央显示规则点阵（每行最多 5 点，0 显示空点阵），答案使用阿拉伯数字。
- 家长可完全在本机添加单个数字或区间（如 `40-50`）。21 以上不显示点阵，中央自动显示英文和中文数字名称；支持到 999,999,999，一次最多添加 100 个连续数字，本机最多保存 300 个自定义数字。
- 学习时把对应的本地暖色卡通图片放大显示在画面中央。
- 可点击大字母或数字，也可直接使用键盘作答；多位数支持连续输入。
- 题目只播放“字母、英文物品、中文物品”的预生成读音；字母和英文单词之间保留约 0.8 秒停顿，不播放操作指令。
- 数字题只播放“英文数字、中文数字”，不播放操作指令。
- 四档难度：新手显示图片与词或点阵；简单只显示图片或点阵；中等只播放读音；困难在只听读音的基础上加入本题与本轮失败规则。
- 困难模式同题连续错误 2 次会结束本题；累计失败上限可由家长设为 1–5 题，默认 3 题。
- 答对后显示对应事物、中英文名称、星星动画和声音反馈；正确或错误动画都可以点击或按键跳过。
- 游戏使用柔和的原创纯音乐《Gentle Ocean Play》，家长可调节音量，读音播放时会自动降低音乐音量。
- 长按 3 秒进入家长区，可添加或移除数字、分别查看字母与数字记录、调整声音和困难模式上限。
- 家长扩词完全本地：输入中文或英文，从 19 个安全候选词中识别，上传自己的图片，预览确认后加入。不会搜索网络图片或安装模型。
- 无需注册或登录；学习记录、家长图片与统计仅保存在每个孩子自己的设备中。
- 不使用账号、服务器数据库、广告、追踪、麦克风或摄像头。
- 所有网页、字体、内置图片、读音和程序资源都随项目保存，并提供离线缓存。

家长可以把公开游戏链接直接发给朋友。每台设备各自保存进度，设备之间不会互相看到或同步孩子的数据；清除浏览器数据会同时清除该设备上的学习记录。

当前附带 101 条物品语音、21 条 0–20 数字语音，以及 31 个英文和 15 个中文数字语音片段。英文单词与数字主要使用自然、清晰的 Ava 多语言美式音色，少数易混淆短词使用逐项复核后更清楚的同系列友好音色；字母使用逐项测试的 Jenny/Ava 教学读法，其中 A、E、P 单独调整语速以保留完整长音；普通话统一使用温和的 Xiaoxiao 标准普通话音色。所有片段都在开发阶段生成、复核并统一响度，同时为轻辅音保留安全起音。字母和英文单词之间保留约 0.8 秒停顿。21 以上数字在本机用短语音片段组合读出，无需联网生成。游戏只包含总计约 6.54 MB 的音频文件，语音工具和语言模型都不会复制进分享版；游玩、添加数字和家长扩词时不会下载模型或连接语音服务。第三方说明见 `THIRD_PARTY_NOTICES.md`。

## 本地运行

普通试玩无需执行下面的开发步骤，直接使用最外层的 `打开游戏.html` 即可。

网页项目位于 `web` 文件夹：

```powershell
cd web
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 构建与发布

- `npm run build`：生成 Sites 版本。
- `npm run build:pages`：在 `GITHUB_PAGES=true` 环境中生成 GitHub Pages 静态版本。
- `npm run build:portable`：重新生成无需安装的一键分享文件夹。
- GitHub Actions 使用 `/AlphabetAndThings/` 作为 Pages 基础路径，并在 `main` 更新后发布。

开发期内容检查可运行 `python tools/validate_game_content.py`，它会确认 82 个内置词、19 个本地扩展词、101 个物品音频、21 个完整数字音频、46 个组合数字语音片段、停顿、图集和 25 张独立图片完整对应。

当前开发分支为 `feature/initial-game`。未经批准不会合并到 `main`。
