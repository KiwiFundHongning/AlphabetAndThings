# AlphabetAndThings

一款面向三岁儿童的中英双语字母与常见事物认知小游戏。

- 仓库：https://github.com/KiwiFundHongning/AlphabetAndThings
- GitHub Pages（合并后启用）：https://kiwifundhongning.github.io/AlphabetAndThings/
- 第一阶段字母：A–P、R–U、W、Z（暂不包含 Q、V、X、Y）

## 最简单的游戏入口

在项目最外层双击 **`打开游戏.html`** 即可开始，不需要安装、登录或联网。

要分享给朋友时，只需压缩整个 **`AlphabetAndThings-分享版`** 文件夹。朋友解压后双击其中的 **`打开游戏.html`**，Windows 和 Mac 都会使用默认浏览器运行。请不要只发送单独的 HTML 文件，因为旁边的 `audio` 和 `things` 文件夹包含本地声音和图片。

## 当前体验

- 每轮随机练习 5 个字母，题目会在同一首字母的多个物品之间轮换。
- 内置 58 个常见物品，包含动物、工程车辆、其他交通工具、水果、蔬菜和日用品。
- 学习时把对应的本地暖色卡通图片放大显示在画面中央。
- 可点击大字母，也可直接按键盘上对应的字母键作答。
- 题目只播放“字母、英文物品、中文物品”的预生成读音；字母和英文单词之间保留约 0.8 秒停顿，不播放操作指令。
- 四档难度：新手显示图片和词；简单只显示图片；中等只播放读音；困难在只听读音的基础上加入本题与本轮失败规则。
- 困难模式同题连续错误 2 次会结束本题；累计失败上限可由家长设为 1–5 题，默认 3 题。
- 答对后显示对应事物、中英文名称、星星动画和声音反馈；正确或错误动画都可以点击或按键跳过。
- 游戏使用低音量原创纯音乐《Gentle Ocean Play》，读音播放时会自动降低音乐音量。
- 长按 3 秒进入家长区，可查看字母记录、调整声音和困难模式上限。
- 家长扩词完全本地：输入中文或英文，从 23 个安全候选词中识别，上传自己的图片，预览确认后加入。不会搜索网络图片或安装模型。
- 无需注册或登录；学习记录、家长图片与统计仅保存在每个孩子自己的设备中。
- 不使用账号、服务器数据库、广告、追踪、麦克风或摄像头。
- 所有网页、字体、内置图片、读音和程序资源都随项目保存，并提供离线缓存。

家长可以把公开游戏链接直接发给朋友。每台设备各自保存进度，设备之间不会互相看到或同步孩子的数据；清除浏览器数据会同时清除该设备上的学习记录。

当前附带的 81 条语音在开发时使用清晰、稳定的标准美式英语音色 `en-US-AvaNeural` 和标准普通话音色 `zh-CN-XiaoxiaoNeural` 预生成。每个字母都使用明确的英文名称读法，而不是让语音引擎猜测单个字符。游戏只包含总计约 2.65 MB 的短 MP3 文件，游玩和家长扩词时都不会下载语言包、模型或连接语音服务。第三方说明见 `THIRD_PARTY_NOTICES.md`。

## 本地运行

普通试玩无需执行下面的开发步骤，直接使用最外层的 `打开游戏.html` 即可。

网页项目位于 `web` 文件夹：

```powershell
cd web
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 构建与发布

- `npm run build`：生成 Sites 版本。
- `npm run build:pages`：在 `GITHUB_PAGES=true` 环境中生成 GitHub Pages 静态版本。
- `npm run build:portable`：重新生成无需安装的一键分享文件夹。
- GitHub Actions 使用 `/AlphabetAndThings/` 作为 Pages 基础路径，并在 `main` 更新后发布。

开发期内容检查可运行 `python tools/validate_game_content.py`，它会确认 58 个内置词、23 个本地扩展词、81 个音频文件、两段停顿和两张本地图集完整对应。

当前开发分支为 `feature/initial-game`。未经批准不会合并到 `main`。
